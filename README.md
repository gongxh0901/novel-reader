# Novel Reader

> 在 Cursor / VSCode 中摸鱼看小说 📖

在编辑器侧栏安静地阅读小说，不需要切换窗口，老板来了一键隐藏。

## 功能

- **侧栏阅读** — 小说内容显示在资源管理器面板中，伪装成项目文件
- **快捷键翻页** — `Cmd+7` 上一页，`Cmd+9` 下一页（Windows 为 `Ctrl`）
- **老板键** — `Cmd+5` 一键隐藏/恢复整个阅读面板
- **显示/隐藏** — `Cmd+8` 切换阅读内容的可见性
- **页码跳转** — 直接跳转到任意页
- **进度记忆** — 自动保存阅读位置，下次打开继续
- **文件监听** — 小说文件修改后自动重载
- **自定义排版** — 可调整每页行数、每行字符数

## 快速开始

1. 安装插件后，按 `Cmd+5`（`Ctrl+5`）激活阅读面板
2. 点击面板标题栏的 📂 图标打开小说文件（支持 `.txt` `.text` `.md`）
3. 使用快捷键翻页阅读

## 快捷键

| 功能 | Mac | Windows / Linux |
|------|-----|-----------------|
| 上一页 | `Cmd+7` | `Ctrl+7` |
| 显示/隐藏 | `Cmd+8` | `Ctrl+8` |
| 下一页 | `Cmd+9` | `Ctrl+9` |
| 老板键 | `Cmd+5` | `Ctrl+5` |

## 配置项

| 配置 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `novelReader.filePath` | string | `""` | 小说文件路径 |
| `novelReader.linesPerPage` | number | `5` | 每页显示行数（1-50） |
| `novelReader.charsPerLine` | number | `25` | 每行最大字符数（5-200） |
| `novelReader.currentPage` | number | `1` | 当前页码（自动更新） |
